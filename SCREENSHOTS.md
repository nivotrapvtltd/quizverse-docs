# Real screenshot capture sheet

Capture only from a running QuizVerse build connected to the included Laravel API/admin panel. Do not use images from `Docs/`; they belong to a different product template.

## Capture rules

- Use a test account and remove personal data before publishing.
- Do not add device frames, stock photos, or AI-generated UI.
- Export PNG at 2x scale. Keep the source image uncompressed.
