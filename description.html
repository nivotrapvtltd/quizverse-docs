QuizVerse | Flutter Quiz & Learning App with Laravel Admin Panel

A self-hosted quiz, exam preparation, gamification, and learning platform for Android and iOS.

QuizVerse is a complete, self-hosted learning and quiz platform designed for educators, institutions, exam preparation centers, and app publishers. It pairs a high-performance Flutter mobile app for Android and iOS with a feature-rich Laravel 12 REST API and browser-based administration panel. Create and manage quiz content, launch timed contests, run competitive 1v1 and group battle modes, configure coin store packages and VIP subscription plans, and offer multiple engaging learning modes.

Your purchase is a complete system package, including three interconnected components:

  • Flutter Mobile App — Mobile App built in Flutter for Android & iOS
  • Admin Panel — Web Administration Panel built in Laravel
  • Backend REST API — Secure REST API built with Laravel 12 & Laravel Sanctum

Who Is This For?

QuizVerse solves the need for an all-in-one educational and trivia platform. Whether you are building an exam preparation portal or a viral gamified quiz app, QuizVerse provides all the tools required out of the box:

  • Educational Institutions & Coaching Centers — Conduct online tests, mock exams, and topic-wise practice quizzes
  • EdTech Startups & Publishers — Monetize content with VIP membership plans, coin economy, and AdMob ads
  • Trivia & Gaming Platform Owners — Host real-time 1v1 and group battle grounds with rewards and leaderboards
  • Content Creators & Educators — Upload and manage questions efficiently with the Quiz Zone bulk import feature

Diverse Quiz & Play Modes Included

  • Quiz Zone: Structured learning by category, subcategory, and level with progression unlocking
  • Battle Zone (1v1 & Group Battle): Real-time competitive quiz battles with live scoring and automatic bot fallback
  • Daily Quiz & Login Streak: Keep users coming back daily with streak counters and daily reward bonuses
  • Exam Preparation: Timed exam papers with custom rules, section navigation, and post-exam solution review
  • Audio Quiz: Listen to audio files and answer comprehension questions
  • Math Mania: Solve mathematical expressions and equations
  • Fun & Learn: Read educational articles/passages and test comprehension
  • Guess the Word: Interactive word puzzle and vocabulary building mode
  • Live Contests: Scheduled quiz tournaments with custom entry fees, prizes, and rank leaderboards

Flutter Mobile App Features

  • Firebase Authentication — Support for Email/Password, Mobile OTP, Google Sign-In, and Apple Sign-In
  • Quiz Zone with category taxonomy, level unlocked flow, and answer bookmarking
  • Battle Ground with 1v1 multiplayer matchmaking, group room codes, and bot fallback support
  • Exam Mode with timed papers, instructions, navigation grid, and full score analysis
  • Gamification — Lifelines (50:50, Skip, Audience Poll, Reset Timer), streak counters, and rewards
  • In-App VIP Subscriptions integrated with Playstore Latest Billing Library
  • Subscription Billing History and coin wallet transaction logs
  • Leaderboards (Daily, Monthly, All-Time) with badge rankings
  • User profile, activity statistics, referral system, and coin wallet store
  • Light and Dark mode support with smooth animations
  • Push notifications via Firebase Cloud Messaging (FCM)

Laravel Admin Panel Features

  • Dashboard: Real-time overview of users, active subscriptions, revenue metrics, and question counts
  • Quiz Zone & Bulk Import: Category management, master question bank, and bulk import tool for Quiz Zone
  • Battle Ground Settings: Configure battle entry fee, coin rewards, turn timers, and bot behavior
  • Subscriptions & Billing History: Create VIP subscription tiers, track billing history logs, and manage payment records
  • Monetization & Coin Store: Define coin store pricing packages, rewarded ad settings, and AdMob units
  • Content Modules: Manage Audio Quiz, Math Mania, Fun & Learn, Guess the Word, Exam Papers, and Live Contests
  • User & Role Management: Manage registered learners, staff roles, permissions, and wallet adjustments
  • Banners & Pages: Carousel banner manager, Privacy Policy, Terms & Conditions, and custom CMS pages

Laravel API Features

  • Powered by Laravel 12 and PHP 8.3+ for maximum performance
  • Laravel Sanctum bearer token authentication for all mobile client endpoints
  • Web Installation Wizard GUI for guided browser-based setup
  • RESTful JSON API endpoints structured for mobile clients

Technical Requirements

  • PHP: 8.3 or later
  • Laravel: 12.x
  • MySQL: 8.0 or later
  • Flutter SDK: Compatible with Dart SDK constraint ^3.12.0
  • Node.js & Composer: Node.js 18+ and Composer 2.x
  • Required PHP Extensions: OpenSSL, PDO, Mbstring, Tokenizer, XML, Ctype, JSON, BCMath, Fileinfo, cURL, ZIP
  • Server: Apache with mod_rewrite or Nginx — Shared Hosting / cPanel / VPS compatible
